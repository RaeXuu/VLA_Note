# 规划（Planning）

在给定地图和当前状态的情况下，找出一条从起点到目标的无碰路径（路径规划）和时序上可行的轨迹（轨迹规划）。

---

## 一、路径 vs 轨迹

| | 路径（Path） | 轨迹（Trajectory） |
|------|------|------|
| **输出** | 空间中的一条曲线 | 带时间信息的路径 |
| **形式** | $\{p_0, p_1, \dots, p_N\}$ | $\{p(t), \dot{p}(t), \ddot{p}(t)\}, t \in [0, T]$ |
| **关心** | 几何可行性（不撞） | 几何 + 动力学约束（不撞 + 能飞/能跑） |
| **先后顺序** | 先算出来 | 在路径基础上加时间参数化 |

> 通常的 pipeline：全局路径规划（sec 级）→ 局部轨迹优化（毫秒级，考虑动态障碍）

---

## 二、配置空间（Configuration Space, C-Space）

**核心思想**：把规划从复杂的 3D 工作空间转换到"配置空间"——每个坐标轴对应对一个关节/DoF。

| 概念 | 含义 |
|------|------|
| **Work Space (W)** | 机器人工作的物理 3D 空间 |
| **Configuration Space (C)** | 机器人所有自由度取值组成的空间。机械臂常是关节角空间；移动机器人可包含 $SE(2)$ / $SE(3)$ 位姿，不一定是简单的 $\mathbb{R}^n$ |
| **Free Space (C_free)** | C-Space 中不碰撞的区域 |
| **Obstacle Space (C_obs)** | C-Space 中会碰撞的区域 |

**为什么需要 C-Space**：在 Work Space 中找一条无碰路径是高度非凸的 NP-hard 问题；映射到 C-Space 后，规划问题是找一条穿过 $C_{\text{free}}$ 的连续曲线。

**C-Space 障碍物**比 Work Space 障碍物更大——因为机械臂本身有体积。把连杆长度、夹具尺寸"膨胀"到障碍物上再做规划。

---

## 三、基于搜索的路径规划

把 $C_{\text{free}}$ 离散化为图，在图里搜索最短路径。

### A*（A-Star）

带启发式的 Dijkstra 变体：

$$f(n) = g(n) + h(n)$$

- $g(n)$ — 起点到节点 $n$ 的实际代价
- $h(n)$ — 节点 $n$ 到目标的启发式估计（必须 **admissible**，即不高估）

**admissible 启发式**：$h(n) \le h^*(n)$（真实最短距离）。欧氏距离在无障碍时等于最短路径、有障碍时小于真实路径 → admissible。

| 变体 | 特点 |
|------|------|
| **Dijkstra** | $h(n)=0$，退化无启发 |
| **A\*** | 有启发式的代价最小优先 |
| **D\*** / **D\* Lite** | 动态环境，障碍物变化时增量重规划 |
| **Theta\*** | 不限于网格边，允许任意方向直线 |

### 格子规划（Lattice Planner）

不搜索 4/8 连接的网格，而是用预先计算的**运动基元**（短轨迹片段），每个基元满足机器人运动学约束：

```
当前位置 ──直走──→ 下一节点
          ──左转──→
          ──右转──→
```

**优点**：搜索结果是物理可行（kinodynamically feasible）的路径，不只是一个几何曲线。

## 四、基于采样的规划

C-Space 维度高时，网格离散化指数爆炸。采样方法在高维中更高效。

### RRT（Rapidly-exploring Random Tree）

```
1. 在 C-Space 随机采样点 x_rand
2. 在树中找到离 x_rand 最近的节点 x_near
3. 从 x_near 向 x_rand 方向延伸一步，得到 x_new
4. 如果 x_new 在 C_free 中，加入树
5. 重复直到 x_new 接近目标
```

**特点**：概率完备（只要存在路径，采样足够多必找到），但路径不是最优的——zig-zag 很多。

### RRT*

RRT 的改进版：新节点加入时检查周围节点，尝试**重新布线**（rewire）——如果经新节点的路径更短，替换父节点。

**代价**：每次迭代需要邻域查询、选择父节点和 rewiring，计算量高于 RRT。**结果**：渐进最优（采样越多越接近最优路径）。

### PRM（Probabilistic Roadmap）

先离线建图，再在线查询的多查询规划器：

1. **建图阶段**：在 C_free 随机采样节点，局部连接成图
2. **查询阶段**：在图中用 A* 搜

适合静态环境重复查询（如工厂场景固定、但目标不断变化）。

## 五、轨迹优化

路径有了，加时间维度和动力学约束。

### 最小 Snap 轨迹

对四旋翼/移动机器人，最小化位置的四阶导数（snap）：

$$\min_{p(t)} \int_0^T \|p^{(4)}(t)\|^2 dt$$

| 阶数 | 物理含义 | 最小化它为了... |
|:----:|------|------|
| 1 | velocity | 最小能量 |
| 2 | acceleration | 最小力 |
| 3 | jerk | 最小冲击（jerk），舒适度 |
| 4 | snap | 最小控制变化率 |

多项式轨迹参数化为分段多项式，在 waypoint 处保证连续性（位置/速度/加速度），通过 QP（二次规划）求解。

### TOPP（Time-Optimal Path Parameterization）

给定一条几何路径，找到时间最短的沿路径速度剖面 $\dot{s}(t)$——即在不超出速度/加速度/力矩约束的前提下，**多快能走完**。

$$\min_{\dot{s}(t),\,T} T \quad \text{s.t.} \quad 0 \le \dot{s} \le \dot{s}_{\max},\; \ddot{s}_{\min} \le \ddot{s} \le \ddot{s}_{\max},\; s(0)=0,\; s(T)=1$$

## 六、方法选择

| 场景 | 推荐方法 |
|------|---------|
| 2D 移动机器人，静态地图 | A* / D* Lite |
| 6+ DoF 机械臂 | RRT* / PRM + 轨迹优化 |
| 无人机穿越 | 格子搜索 + 最小 snap |
| 动态障碍、高速场景 | MPC（模型预测控制，规划+控制一体） |
| 工厂固定环境反复查询 | PRM |
| 狭窄通道 | PRM/RRT 的改进采样（bridge test、Gaussian sampling、目标偏置）或优化型 planner；普通 RRT 的 Voronoi bias 更偏向探索空旷区域，狭窄通道反而容易采不到 |

---

## 七、与控制的边界

规划输出**轨迹**（位姿+速度+加速度的时序序列），控制接收轨迹、用反馈律跟踪它。两者有重合地带——MPC 既是规划也是控制。

在 pipeline 里：规划 ≈ "想清楚怎么走"，控制 ≈ "跟住计划好的路"。
