# 脚踏式实时标注器

## 目标

设计类似电吉他综合效果器的脚踏设备，在机器人示教过程中记录阶段边界，减少事后数据标注工作。设备与视觉、触觉、夹爪状态和位姿数据使用统一时间轴。

## 标签结构

### 轨迹级信息

示教开始前设置，整条轨迹内保持不变：

- 环境：室内 / 户外
- 物体类别
- 物体属性：刚体 / 柔性 / 可变形
- 任务类型
- 操作者与实验配置

### 时间相关标注

为任务预设固定阶段模板，例如：

```text
Motion → Contact → Pick-up → Transport → Place
```

操作者每踩一次 `Next Phase`，设备记录时间戳并进入下一阶段，由系统自动生成各阶段的起止区间。

## 踩钉设计

| 踩钉 | 操作 | 功能 |
|---|---|---|
| Next Phase | 短踩 | 推进任务阶段并记录时间戳 |
| Outcome | 短踩 | Success，结束轨迹 |
| Outcome | 长踩 | Fail，结束轨迹 |
| Needs Review | 踩下 | 标记该轨迹需要人工审核 |

误触或流程严重错误的轨迹直接标记为 `discarded`，不设置 Undo。

## 硬件方案

- 金属效果器外壳
- 3 个踩钉
- Raspberry Pi
- RGB LED 与蜂鸣器反馈
- USB 接口
- 可选 OLED 状态显示屏

## 数据输出

```json
{
  "episode_id": 12,
  "metadata": {
    "environment": "indoor",
    "object_material": "deformable",
    "task": "pick_and_place"
  },
  "phases": [
    {"name": "motion", "start": 0.0, "end": 4.2},
    {"name": "contact", "start": 4.2, "end": 5.1},
    {"name": "pick_up", "start": 5.1, "end": 7.8}
  ],
  "result": "success",
  "needs_review": false
}
```

## 研究问题

- 实时脚踏标注能否减少事后标注时间？
- 阶段边界与人工事后标注相比有多大时间误差？
- 结构化阶段标签能否提升视觉—触觉状态估计或操作策略的性能？
- 系统能否将人工工作从完整标注降低为异常轨迹审核？
