# 触觉结合 VLA 与世界模型研究进展：笔记设计

## 目标

在 `Large-scale Machine Learning/` 中新建一篇中文综述笔记，帮助读者快速建立“触觉 + 视觉—语言—动作模型（VLA）”与“触觉 + 世界模型（World Model）”的当前研究地图。

## 读者与深度

- 面向机器人学研究生入门阶段。
- 中文为主，英文术语首次出现时标注中文。
- 以技术直觉、问题定义、方法分类和代表工作为主，不做教科书式穷举。
- 用途是快速建立研究地图，而非围绕单一论文做复现手册。

## 调研边界

- 检索截止日期：2026-08-09。
- 覆盖同行评审论文、arXiv 预印本、官方项目页与必要的企业技术报告。
- 明确区分已同行评审结果、预印本结果与企业演示；不把宣传性表述当作学术共识。
- 优先使用原始论文、会议页面、项目页和代码仓库等一手资料。

## 组织方法

采用“问题驱动的研究地图”，不按年份简单堆叠论文。先解释纯视觉在接触丰富操作中的信息缺口，再分别建立触觉进入 VLA 和世界模型的方法谱系，最后汇总数据、评测和规模化瓶颈。

## 正式笔记结构

1. 核心结论与研究版图。
2. 为什么 VLA 和世界模型需要触觉。
3. 触觉输入与表示：力/力矩、触觉阵列、视觉式触觉传感器与 tactile token。
4. 触觉 + VLA：输入级、特征级与 token 级融合；快慢系统；高频反馈；灵巧操作与遮挡。
5. 触觉 + 世界模型：未来触觉预测；视觉—触觉联合动力学；跨模态生成；接触状态建模；基于模型的规划与控制。
6. 代表工作对比表：年份、发表状态、传感器、模型类型、任务、真实机器人验证与核心贡献。
7. 数据集、预训练、评测与规模化瓶颈。
8. 当前共识、未解问题与未来趋势。
9. 初学者阅读路线。
10. 参考文献与可访问链接。
