- **批量梯度下降(BGD)**
    

普通的梯度下降算法在更新参数时要遍历整个数据集，是一种批处理方法。训练数据特别庞大时，**单次更新可能非常慢**，因为梯度来自所有样本损失的平均值。如果损失曲面非凸、存在多个**局部极小值**或鞍点，就不能保证找到全局最小值。

  

- **随机梯度下降(SGD)**
    

随机梯度下降的思想是根据每个单独的训练样本来更新权值，换言之，如果每次迭代过程中都要对 n个样本进行求梯度，开销会非常大，而随机梯度下降的思想就是**随机采样一个样本来更新参数**，计算开销从 O(n)下降到 O(1)。

![[5bd2823cf31f.png]]

有了上面权重的更新公式后，我们就可以通过输入大量的实例样本，来根据我们预期的结果不断地调整权值，从而最终得到一组权值使得我们的算法能够对一个新的样本输入得到正确的或无限接近的结果。

- **小批量梯度下降(MBGD)** Mini-Batch Gradient Descent
    

小批量梯度下降Mini-Batch Gradient Descent 算法是介于传统梯度下降算法(批量梯度下降)和随机梯度下降算法之间的算法，每计算常数b次训练实例，便更新一次参数θ。

换言之，对于每更新一次θ，传统梯度下降算法遍历整个数据集m个样本，SGD则每更新一次θ遍历1个样本，而小批量梯度下降每更新一次θ遍历b个数据样本，b取值范围通常介于2~100之间

- **Adam**
    

1. 第一步：计算一阶矩 $m_t$（动量项）
    

这部分模仿了物理中的惯性，累积过去的梯度方向：

$$m_t = \beta_1 \cdot m_{t-1} + (1 - \beta_1) \cdot g_t$$

**作用：** 抑制震荡，让更新方向更平滑。

2. 第二步：计算二阶矩 $v_t$（缩放项）
    

这部分记录了梯度波动的剧烈程度：

$$v_t = \beta_2 \cdot v_{t-1} + (1 - \beta_2) \cdot g_t^2$$

**作用：** 用来缩放学习率。如果某个参数的梯度一直很大，$v_t$ 就大，实际步长就会变小，防止发散。

3. 第三步：偏置修正（Bias Correction）
    

由于 $m_t$ 和 $v_t$ 在初始时通常设为 0，会导致训练初期这两个值偏向 0。Adam 通过以下公式修正：

$$\hat{m}_t = \frac{m_t}{1 - \beta_1^t}, \quad \hat{v}_t = \frac{v_t}{1 - \beta_2^t}$$

4. 第四步：参数更新
    

$$\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \cdot \hat{m}_t$$

$\eta$ 是学习率，$\epsilon$ 是防止分母为 0 的极小值（如 10 ^-8）。

- **其他优化算法**
    

|                |                                                                |                                          |                            |
| -------------- | -------------------------------------------------------------- | ---------------------------------------- | -------------------------- |
| 算法名称           | 核心机制 (Key Idea)                                                | 优点                                       | 缺点                         |
| Momentum (动量法) | 引入物理“惯性”，累积之前的梯度方向：$v_t = \gamma v_{t-1} + \eta \nabla \theta$ | 抑制震荡，加速经过平坦区域，减少在峡谷地带的徘徊。                | 需要手动调节动量参数 $\gamma$。       |
| Nesterov (NAG) | “提前量”预测，在更新点的前方计算梯度。                                           | 比普通动量法更具前瞻性，防止冲过头，更加稳定。                  | 计算稍微复杂一点点。                 |
| Adagrad        | 自适应学习率：给稀疏特征（更新频率低）较大的学习率，给频繁特征较小的学习率。                         | 适合处理稀疏数据（如 NLP 中的长尾词更新）。                 | 学习率会随着迭代不断单调递减，导致后期无法收敛。   |
| RMSprop        | 改进 Adagrad，使用指数加权移动平均来计算梯度平方。                                  | 解决了 Adagrad 学习率过早消失的问题。                  | 仍然需要手动设定全局学习率。             |
| Adam (常用默认基线)  | 结合体：同时利用了一阶动量（Momentum）和二阶动量（RMSprop）。                         | 收敛快，通常比 SGD 少调参。                | 并非对超参数不敏感；在某些视觉任务中可能泛化性能略逊于调优后的 SGD。 |
| AdamW          | 在 Adam 的基础上修正了权重衰减 (Weight Decay) 的逻辑。                         | 在正则化效果上优于 Adam，目前是大模型（Transformer）训练的主流。 | 增加了一个解耦的权重衰减系数。            |
