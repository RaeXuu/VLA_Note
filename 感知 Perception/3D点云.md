# 3D 点云（3D Point Cloud）

**点云**是三维空间中一组离散点的集合，每个点包含 $(x, y, z)$ 坐标，可附带颜色、法向量、强度等属性。点云是 3D 感知的最基础数据格式——介于 2D 图像（有序网格）和 3D 网格（完整表面）之间。

$$\mathcal{P} = \{ \mathbf{p}_i \mid \mathbf{p}_i \in \mathbb{R}^3,\ i = 1, \dots, N \}$$

---

## 一、点云的基本性质

### 1.1 三大核心属性

| 属性 | 含义 | 对算法的要求 |
|------|------|------|
| **无序性（Unordered）** | 点的排列顺序不影响点云表示的几何形状——同一个点集，无论按什么顺序存储，表示的物体相同 | 算法必须对输入排列具有不变性（permutation invariance） |
| **稀疏性（Sparsity）** | 点只分布在物体表面，3D 空间中绝大部分是空的 | 体素/Voxel 表示会浪费大量内存和计算 |
| **不规则性（Irregular）** | 点不是均匀分布在规则网格上的，密度可能随距离、反射率变化 | 卷积等网格操作不能直接套用 |

### 1.2 与 2D 图像的本质区别

| | 2D 图像 | 3D 点云 |
|------|------|------|
| **数据结构** | 规则二维网格 | 无序离散点集 |
| **信息密度** | 密集（每像素有值） | 稀疏（只在物体表面有点） |
| **尺度变化** | 近大远小（投影效应） | 尺度不变（绝对 3D 坐标） |
| **遮挡** | 丢失被遮挡的 2D 像素 | 不完整的 3D 表面 |
| **卷积效率** | 高（网格相邻定义明确） | 低（需要定义 3D 空间中的邻域） |

## 二、获取方式（Acquisition）

| 传感器类型 | 原理 | 代表设备 | 点云特点 |
|------|------|------|------|
| **LiDAR（激光雷达）** | 发射激光脉冲，测量往返时间（ToF） | Velodyne, Ouster, Livox | 稀疏、远距离、含强度，有环形扫描模式 |
| **RGB-D 相机** | 结构光或主动立体匹配 | Intel RealSense, Kinect, Orbbec | 稠密、近距离（< 10m）、有 RGB 对齐 |
| **SfM（运动恢复结构）/ MVS（多视角立体）** | 多张 2D 图像三角测量 | COLMAP, RealityCapture | SfM 通常先得到稀疏点云，MVS 再补成稠密点云；弱纹理、反光、重复纹理会失败 |
| **固态/半固态 LiDAR** | MEMS、OPA、Flash 等不同扫描/成像机制 | RoboSense, Hesai, Livox 等 | 形态多样，可能无旋转部件或小范围扫描；是否“均匀稠密”取决于具体结构，不是所有固态 LiDAR 都一样 |

### 2.1 各传感器适用场景

- **自动驾驶：** LiDAR（测距远 > 100m，户外稳定）为主，RGB-D 距离不够
- **室内机器人/机械臂：** RGB-D 相机（距离够、稠密、能对齐彩色纹理给 VLM 多用）
- **3D 重建：** SfM/MVS（用照片重建场景，成本最低）
- **服务机器人：** 混合——近距 RGB-D + 远距 LiDAR

## 三、点云处理基础操作

### 3.1 滤波（Filtering）

| 操作 | 目的 | 代表算法 |
|------|------|------|
| **降采样（Downsampling）** | 减少点数，降低计算量，均匀化密度 | 体素网格滤波（Voxel Grid Filter） |
| **去噪（Denoising）** | 去除测量噪声点 | 统计离群点移除（SOR），半径离群点移除（ROR） |
| **平滑（Smoothing）** | 让表面更光滑，去除高频噪声 | MLS（移动最小二乘），双边滤波 |
| **地面分割** | 去除地面点，简化后续处理 | RANSAC 平面拟合，Cloth Simulation Filter |

### 3.2 最近邻搜索（Nearest Neighbor Search）

点云处理中**最频繁调用**的基础操作——几乎所有操作（法向量估计、分割、配准、邻域特征）都要找"一个点周围的邻近点"。

| 数据结构 | 构建时间 | 查询时间 | 适用 |
|------|:------:|:------:|------|
| **KD-Tree** | $O(N \log N)$ | $O(\log N)$（平均） | 低维（3D），最常用 |
| **Octree（八叉树）** | $O(N \log N)$ | $O(\log N)$ | 自适应密度变化 |
| **Ball Tree** | $O(N \log N)$ | $O(\log N)$ | 高维数据 |

**直觉：** 不用 KD-Tree 的暴力搜索 $O(N^2)$——对每个点遍历所有点找邻居。KD-Tree 将空间递归划分为二叉树，每次排除一半空间，查询降到 $O(\log N)$。这是点云加速的关键。

### 3.3 法向量估计（Normal Estimation）

对每个点 $\mathbf{p}$，在其邻域 $\mathcal{N}(\mathbf{p})$ 内拟合平面，平面的法向量即该点的法向量。

等价于对邻域点的 $3 \times 3$ 协方差矩阵做 PCA（主成分分析），最小特征值对应的特征向量即法向量方向。

**法向量方向一致性**是核心问题：邻域点的法向量可能指向物体内部或外部，需要根据视角或传播方向统一。没有法向量的点云就像没有梯度的函数——没法判断表面朝向。

### 3.4 特征描述子（Feature Descriptor）

为每个关键点计算一个固定维度的特征向量（描述子），用于匹配不同视角的同一点。

| 描述子 | 原理 | 特点 |
|------|------|------|
| **PFH（Point Feature Histogram）** | 邻域点对之间的角度/距离统计直方图 | 125 维，慢 |
| **FPFH（Fast PFH）** | PFH 加速版 | 33 维，快，最常用 |
| **SHOT** | 带空间划分的签名直方图 | 352 维，含颜色 |
| **3DSC（3D Shape Context）** | 以该点为中心的球坐标系密度分布 | 抗噪声，计算重 |

## 四、点云配准（Point Cloud Registration）

**核心问题：** 给定两帧不同视角的点云，找到它们之间的刚体变换 $\mathbf{R}, \mathbf{t}$，将它们对齐到同一坐标系下。

### 4.1 ICP（Iterative Closest Point，迭代最近点）

**最经典算法。** 交替执行两步直至收敛：
1. 找最近点对应（当前变换下，源点云每个点的最近目标点）
2. 用 SVD 求解最优 $\mathbf{R}, \mathbf{t}$ 最小化对应点对的均方距离

- **问题：** 需要好的初始位姿（否则陷局部极小值），对离群点敏感
- **变体：** Point-to-Plane ICP（用点到局部切平面的距离替代点对点距离，收敛通常更快）、GICP
- **适用：** 两帧已经比较接近（~10cm, ~10°）时的精细对齐

### 4.2 粗配准（Coarse / Global Registration）

ICP 需要初始值，粗配准负责提供这个初始值：

- **基于特征匹配：** 提取 FPFH 描述子 → RANSAC 匹配 → 初始变换
- **基于深度学习：** 用网络学习对应关系或直接预测 $\mathbf{R}, \mathbf{t}$

### 4.3 深度学习配准

| 方法 | 思路 |
|------|------|
| **PointNetLK** | 用 PointNet 提取全局特征，在特征空间迭代配准 |
| **DCP（Deep Closest Point）** | Transformer 替代传统最近点对应 |
| **GeoTransformer** | 超点匹配 + Geometric Self-Attention，当前 SOTA |

## 五、点云深度学习

2D 图像的卷积天然适配规则网格。但点云是无序、不规则的离散点集——**如何定义"卷积"是核心挑战**。

### 5.1 PointNet（CVPR 2017）——开山之作

**核心思想：** 每个点独立通过 MLP 升维 → 用 max pooling 聚合全局特征。Max pooling 是 symmetric function（对称函数，输入顺序不影响输出），天然实现排列不变性。

$$f(\mathcal{P}) = \max_{i=1}^{N} \ \text{MLP}(\mathbf{p}_i)$$

- **局限：** 只有全局特征，没有局部几何结构
- **意义：** 证明用最简单的对称函数就能在点云上做深度学习，不需要体素化或投影

### 5.2 PointNet++（NeurIPS 2017）——引入局部

在 PointNet 基础上加入**层级化分组**：

1. **采样（Sampling）：** FPS（最远点采样）选出中心点
2. **分组（Grouping）：** 以每个中心点为圆心，球查询（ball query）找到半径内邻域点
3. **局部 PointNet：** 每个小组内做 mini-PointNet，提取局部特征
4. 重复，逐步扩大感受野（类似 CNN 的 pooling 层扩大感受野）

- **解决了 PointNet 缺少局部结构的问题**
- 成为后续几乎所有点云网络的基础范式

### 5.3 后续发展

| 方法 | 核心贡献 |
|------|------|
| **DGCNN（EdgeConv）** | 在图结构上定义动态边卷积，特征空间中找 KNN 而非坐标空间中 |
| **KPConv（Kernel Point Convolution）** | 用一组三维排列的核心点（kernel points）定义可学习的 3D 卷积核 |
| **Point Transformer** | 将 Transformer 的 self-attention 从 2D 像素适配到 3D 点云 |
| **MinkowskiEngine** | **稀疏 3D/4D 卷积框架**，是大多数 SparseConvNet 系的 back-end。只对非零体素（有点的网格）计算，跳过空间区域的卷积。在实际 3D 语义/实例/检测任务中效果公认好，属于核心 back-end |
| **SparseConvNet** | 将稀疏卷积用于 3D 体素点云，是许多室内外大规模语义分割 backbone 的基础思路之一（有体素的地方才算卷积，跳过空白区域） |

## 六、在机器人中的应用

| 任务 | 点云角色 | 典型管线 |
|------|------|------|
| **目标检测（3D Detection）** | 输入 | PointPillars / CenterPoint → 3D BBox |
| **语义分割（Semantic Segmentation）** | 逐点分类 | MinkowskiEngine / KPConv → 物体/地面/建筑标签 |
| **SLAM（同时定位与建图）** | 定位 + 建图 | LOAM / LeGO-LOAM / Fast-LIO → 位姿 + 地图 |
| **6D 姿态估计** | 物体几何参考 | 点云配准 / Dense Correspondence → R, t |
| **抓取规划** | 物体表面几何 | GPD / PointNetGPD → 抓取点 + 接近方向 |
| **碰撞检测** | 障碍物几何 | FCL（灵活碰撞库）/ Bullet → 安全规划 |
| **具身导航** | 环境几何 | 点云 → Octomap / ESDF → 路径规划 |

## 七、常见点云库

| 库 | 语言 | 定位 | 特色 |
|------|:------:|------|------|
| **PCL（Point Cloud Library）** | C++ | 点云处理全家桶 | 滤波、分割、配准、特征...应有尽有 |
| **Open3D** | C++ / Python | 现代 3D 数据处理 | Python 接口友好，深度学习兼容，可视化好 |
| **PDAL** | C++ / Python | 大规模点云（地理空间） | 侧重激光扫描数据处理 pipeline |
| **Kaolin** | Python | 面向深度学习 | NVIDIA 出品，支持可微渲染 + 点云训练 |
| **PyTorch3D** | Python | 3D 深度学习 | Meta 出品，可微渲染 + 点云/网格/体素 |

**选型：** 日常 Python 项目 → Open3D；C++ 高性能部署 → PCL；深度学习训练 → PyTorch3D / Kaolin。

## 八、关键概念速查

- **Voxel Grid（体素网格）：** 将 3D 空间划分为规则立方体网格，有点的体素值为 1。把无序点云转为有序 3D 张量——可套用 3D 卷积，但内存消耗 $O(n^3)$ 随分辨率爆炸
- **FPS（最远点采样，Farthest Point Sampling）：** 从点云中均匀采样 $k$ 个点——每次选离已选点集最远的点。$O(kN)$ 计算量。PointNet++ 等层级网络的核心采样操作
- **Ball Query（球查询）：** 以某点为中心，在半径 $r$ 的球体范围内找所有邻居点。与 KNN 的区别：用固定空间半径而非固定邻居数，可以自适应点云密度变化
- **Symmetric Function（对称函数）：** $f(x_1, x_2, \dots, x_N) = f(x_{\pi(1)}, x_{\pi(2)}, \dots, x_{\pi(N)})$。Max / Sum / Mean 都是对称函数。PointNet 的核心：用 max pooling 实现排列不变性
- **Permutation Invariance（排列不变性）：** 改变点的输入顺序，网络输出不变。是所有点云网络的必备属性
- **ToF（飞行时间，Time of Flight）：** 发射激光脉冲，测量从发射到接收的时间差 $\Delta t$ → 距离 = $c \cdot \Delta t / 2$。LiDAR 和深度相机的基础测距原理
