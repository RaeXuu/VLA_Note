# 运动学与动力学

## 一、逆运动学（Inverse Kinematics, IK）

由末端位姿反求关节角。

### 1.1 解析解（Analytical / Closed-form）

把末端位姿代入公式，一步算出关节角。

- 利用机器人特定的几何结构（Pieper 准则：三个相邻关节轴相交于一点），推导每个关节角的显式表达式 $\theta_i = f(\text{pose})$
- **$O(1)$，快且可靠，拿到全部解**（通常 6-DOF 臂有 8 组）
- 不是所有机器人都能解 —— 必须满足特定几何条件（不满足则只能用数值解）

### 1.2 数值解（Numerical / Iterative）

从初始猜测出发，反复迭代逼近目标位姿。最经典的是 **Jacobian 伪逆法**：

1. 当前关节角 $\theta$ → 正运动学 → 当前末端位姿
2. 计算误差 $\Delta x$（目标位姿 vs 当前位姿）
3. $\Delta \theta = J^\dagger \Delta x$（Jacobian 伪逆乘以误差）
4. $\theta \leftarrow \theta + \Delta \theta$，重复直到 $\Delta x$ 足够小

其他方法：Newton-Raphson、CCD（循环坐标下降）、基于优化的方法。

- **通用：** 任意自由度、任意关节结构都能用
- 可处理关节限制、避障等约束；可处理冗余（null-space projection 做 subtask）
- **慢、依赖初值、可能不收敛**（奇异点附近 Jacobian 病态、目标不在工作空间）
- 只能拿一个解（取决于初始猜测），无法枚举

### 1.3 对比

| | 解析解 | 数值解 |
|------|------|------|
| **速度** | 极快（代公式） | 慢（迭代） |
| **可靠性** | 100%，必出结果 | 可能发散 |
| **解的数量** | 全部 | 一个 |
| **适用性** | 仅 Pieper 条件 | 任意结构 |
| **冗余处理** | 不自然 | 天然支持（null-space） |
| **约束处理** | 困难 | 可嵌入优化 |
| **典型场景** | 工业 6-DOF 臂（UR5、KUKA） | 冗余臂、人形、灵巧手 |

### 1.4 实际策略

满足 Pieper 条件 → 优先解析解（IKFast / 手写 closed-form）；否则或需要避障 → 数值解（TRAC-IK / KDL / Pinocchio）。常用折中：先试解析解，失败时 fallback 到数值解。
