# 状态估计（State Estimation）

从带有噪声的传感器数据中，推断系统的真实状态。

---

## 一、问题定义

**状态**（state）= 完整描述系统在某一时刻所需的最小变量集合。比如：

| 系统 | 状态向量 |
|------|---------|
| 移动机器人 | $x = [p_x, p_y, \theta, v_x, v_y, \omega]^\top$ |
| 机械臂 | $x = [q_1, q_2, \dots, q_n, \dot{q}_1, \dots, \dot{q}_n]^\top$ |
| 无人机 | $x = [p, v, q, \omega_b]^\top$（位置、速度、朝向四元数、角速度） |

**为什么不能直接测？** 传感器有噪声、有偏置、采样率有限、甚至不直接测量你要的量（比如测加速度，但你要位置）。

---

## 二、贝叶斯滤波——统一框架

所有经典状态估计算法的背后都是同一个贝叶斯递归：

1. **预测步**（先验）：用运动模型预测下一个状态分布

$$p(x_t | z_{1:t-1}, u_{1:t}) = \int p(x_t | x_{t-1}, u_t)\; p(x_{t-1} | z_{1:t-1}, u_{1:t-1})\; dx_{t-1}$$

2. **更新步**（后验）：用新观测修正预测

$$p(x_t | z_{1:t}, u_{1:t}) \propto p(z_t | x_t)\; p(x_t | z_{1:t-1}, u_{1:t})$$

- $x_t$ — 状态
- $u_t$ — 控制/运动输入
- $z_t$ — 传感器观测
- $p(x_t|x_{t-1}, u_t)$ — 运动模型（状态转移）
- $p(z_t|x_t)$ — 观测模型（传感器模型）

**直觉**：先猜一个（预测），再用眼看一下（更新），两者加权平均。传感器比运动模型准 → 更信观测；运动模型比传感器准 → 更信预测。

---

## 三、卡尔曼滤波（Kalman Filter, KF）

线性系统 + 高斯噪声下的**最优**估计器。

### 假设
- 运动模型线性：$x_t = A x_{t-1} + B u_t + w_t$
- 观测模型线性：$z_t = C x_t + v_t$
- 噪声均为零均值高斯：$w_t \sim \mathcal{N}(0, Q)$，$v_t \sim \mathcal{N}(0, R)$

### 两步递归

**预测**（用模型往前推）：
$$\hat{x}_{t|t-1} = A\hat{x}_{t-1} + B u_t$$
$$P_{t|t-1} = A P_{t-1} A^\top + Q$$

**更新**（用观测修正）：
$$K_t = P_{t|t-1} C^\top (C P_{t|t-1} C^\top + R)^{-1} \quad \text{(Kalman Gain)}$$
$$\hat{x}_t = \hat{x}_{t|t-1} + K_t(z_t - C\hat{x}_{t|t-1})$$
$$P_t = (I - K_t C) P_{t|t-1}$$

工程实现里常用 Joseph form：

$$P_t = (I-K_tC)P_{t|t-1}(I-K_tC)^\top + K_t R K_t^\top$$

它和标准形式在精确数学下等价，但数值上更容易保持 $P_t$ 对称正定。

### Kalman Gain 的直觉

$$K_t = \frac{\text{预测不确定性}}{\text{预测不确定性} + \text{观测噪声}}$$

- $Q$ 大（运动不可靠）→ 更信观测 → $K$ 大
- $R$ 大（传感器噪声大）→ 更信预测 → $K$ 小

---

## 四、扩展卡尔曼滤波（EKF）

现实世界中运动模型和观测模型往往**非线性**。EKF 对非线性函数做一阶泰勒展开（即雅可比替代 $A$、$C$）：

$$A_t = \left.\frac{\partial f}{\partial x}\right|_{\hat{x}_{t-1}}, \quad C_t = \left.\frac{\partial h}{\partial x}\right|_{\hat{x}_{t|t-1}}$$

**主要问题**：EKF 假设线性化足够好。高度非线性的系统（如大转角旋转）、初值差或噪声模型不准时，一阶近似可能导致不一致甚至发散。这时可考虑 UKF（无迹卡尔曼滤波）、粒子滤波，或在李群上做误差状态/迭代 EKF。

---

## 五、粒子滤波（Particle Filter）

不假设高斯、不假设线性。用一堆带权重的粒子（样本点）直接近似后验分布：

$$p(x_t | z_{1:t}) \approx \sum_{i=1}^{N} w_t^{(i)} \delta(x_t - x_t^{(i)})$$

**三步循环**：
1. **采样**（重要性采样，从提议分布抽粒子）
2. **权重更新**（用观测计算每个粒子的似然 $w^{(i)} \propto p(z_t | x_t^{(i)})$）
3. **重采样**（复制高权重粒子、丢弃低权重粒子，解决粒子退化）

**经典应用**：移动机器人定位（Monte Carlo Localization, MCL），$N=1000$ 个粒子分布在 2D 地图上，每次更新后粒子逐步收敛到真实位置。

---

## 六、三者的选择

| | KF | EKF | 粒子滤波 |
|------|:--:|:---:|:---:|
| **系统** | 线性 | 可微非线性 | 任意非线性 |
| **噪声分布** | 高斯 | 高斯（近似） | 任意分布 |
| **计算量** | 低 | 中 | 高（粒子越多越准越慢） |
| **高维可用？** | ✓ | ✓ | 维度诅咒（指数爆炸） |
| **典型场景** | IMU+GPS 融合 | SLAM 前端，视觉惯性里程计 | 2D 全局定位 |

---

## 七、图优化——当代主流

KF/EKF 都是**滤波**方法：只维护当前状态，历史信息被压缩进当前均值和协方差，难以回头整体重线性化和重优化。早期错误的数据关联（如错误闭环）会强烈污染后续估计；相比之下，平滑/图优化更容易通过回溯优化、鲁棒核或因子剔除来修正。

**平滑（smoothing）** 维护所有历史状态的联合分布，可以回溯修正。现代 SLAM 几乎全部用图优化（因子图 + 非线性最小二乘，g2o / GTSAM / Ceres）：

$$\arg\min_X \sum_k \| e_k(X_k) \|^2_{\Omega_k}$$

- $X$ — 所有待估计的变量（轨迹点、路标点、标定参数...）
- $e_k$ — 第 $k$ 个约束的残差（状态应满足的关系）
- $\Omega_k$ — 信息矩阵（约束的权重，$\Omega = \Sigma^{-1}$）

**为什么图优化胜出**：信息矩阵天然是稀疏的（大部分变量之间无直接约束），利用稀疏性做增量优化，几千个变量也能实时跑。
