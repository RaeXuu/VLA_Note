# 6D 物体姿态估计（6D Object Pose Estimation）

**6D 姿态** = 3D 位置（Translation, $x, y, z$）+ 3D 朝向（Rotation），共 6 个自由度（DoF）。任务是：给定图像或点云，估计物体从物体坐标系到相机/世界坐标系的刚体变换。

$$\mathbf{T} = \begin{bmatrix} \mathbf{R} & \mathbf{t} \\ \mathbf{0} & 1 \end{bmatrix} \in SE(3)$$

其中 $\mathbf{R} \in SO(3)$ 是旋转矩阵，$\mathbf{t} \in \mathbb{R}^3$ 是平移向量。

---

## 一、旋转表示（Rotation Representation）

这是 6D 姿态里最复杂的部分——平移就是 $\mathbb{R}^3$ 的一个点，但旋转有多种数学表示，各有优劣。

### 1.1 旋转矩阵（Rotation Matrix）

$$\mathbf{R} \in \mathbb{R}^{3 \times 3},\quad \mathbf{R}^T\mathbf{R} = \mathbf{I},\quad \det(\mathbf{R}) = 1$$

- **优点：** 直接对应坐标变换，矩阵乘法就是旋转变换
- **缺点：** 9 个参数但只有 3 个自由度（冗余，6 个约束条件），神经网络输出 9 个数很难保证落在 $SO(3)$ 流形上，需 Gram-Schmidt 正交化或 SVD 投影

### 1.2 欧拉角（Euler Angles）

三个角度：roll（绕 X）、pitch（绕 Y）、yaw（绕 Z）。直觉最自然。

- **优点：** 3 个参数，无冗余，人类可读
- **缺点：万向节死锁（Gimbal Lock）**——pitch = ±90° 时，roll 和 yaw 变得不可区分（失去一个自由度），导致旋转插值和优化出问题。**不用于深度学习的回归目标**

### 1.3 轴角表示（Axis-Angle）

一个单位向量 $\mathbf{u}$（旋转轴）+ 一个标量 $\theta$（绕轴旋转的角度），共 4 参数，但 $\|\mathbf{u}\|=1$ 约束可去掉得 3 参数：$\boldsymbol{\omega} = \theta \mathbf{u}$。

- **物理直觉：** 任何旋转等价于绕某根轴转一个角度
- 常用在机器人学中表示角速度

### 1.4 四元数（Quaternion）

$$q = w + xi + yj + zk = (w, x, y, z),\quad w^2 + x^2 + y^2 + z^2 = 1$$

- **优点：** 4 个参数 + 1 个归一化约束（比旋转矩阵更少冗余），无万向节死锁，平滑插值（slerp，球面线性插值）
- **缺点：** 人类难读，$q$ 和 $-q$ 表示同一个旋转（双覆盖，double cover）
- **神经网络使用：** L2 回归 4 个数 + 输出后 L2 归一化 或 Geodesic Loss（测地距离损失，$1 - |q_{\text{pred}} \cdot q_{\text{gt}}|$）

### 1.5 6D 连续表示（Zhou et al., 2019）

从旋转矩阵的前两列 $(\mathbf{r}_1, \mathbf{r}_2)$ 重构完整旋转矩阵：

1. 网络输出 6 个数 → 重塑为 $\mathbf{a}_1, \mathbf{a}_2 \in \mathbb{R}^3$
2. Gram-Schmidt 正交化：$\mathbf{r}_1 = \frac{\mathbf{a}_1}{\|\mathbf{a}_1\|},\quad \mathbf{r}_2 = \frac{\mathbf{a}_2 - (\mathbf{r}_1 \cdot \mathbf{a}_2)\mathbf{r}_1}{\|\mathbf{a}_2 - (\mathbf{r}_1 \cdot \mathbf{a}_2)\mathbf{r}_1\|}$
3. $\mathbf{r}_3 = \mathbf{r}_1 \times \mathbf{r}_2$

这是深度学习里常用、稳定的旋转回归表示之一，能缓解欧拉角不连续和四元数双覆盖带来的优化问题。注意它只是表示方式，不等于自动解决 $SO(3)$ 上的度量问题；训练时仍常配合 geodesic loss（测地距离损失）或 ADD/重投影类几何损失。

### 1.6 各表示对比

| 表示 | 参数量 | 冗余度 | 万向节死锁 | 神经网络友好 | 插值 |
|------|:------:|:------:|:------:|:------:|:------:|
| 旋转矩阵 | 9 | 高 | 无 | 中（需正交化） | ✓ |
| 欧拉角 | 3 | 无 | **有** | 差 | ✗ |
| 轴角 | 3 | 无 | 无 | 中 | 中 |
| 四元数 | 4 | 低 | 无 | 良 | ✓（slerp） |
| **6D 连续** | 6 | 中 | 无 | **优** | 需先转成旋转矩阵/四元数再插值 |

## 二、姿态估计方法分类

### 2.1 传统方法：基于关键点（Keypoint-based）

```
输入图像 → 检测 2D 关键点（物体角点、纹理点等）
         → 与物体 3D 模型上的对应 3D 关键点匹配
         → PnP（Perspective-n-Point）求解 R, t
```

- **PnP 算法：** 给定 n 对 2D-3D 对应点，已知相机内参，求解外参 $\mathbf{R}, \mathbf{t}$。最少 3 对点（P3P），实际用 PnP + RANSAC 提高鲁棒性
- **代表：** BB8（2017）、PVNet（2019）
- **局限：** 关键点检测精度敏感，遮挡下容易失效

### 2.2 基于模板匹配（Template Matching）

在 6D 空间中搜索，生成物体在不同姿态下的渲染图，与输入图像比较相似度。

- **代表：** Hinterstoisser et al.（LINEMOD 模板法）、AAE（2019，自编码器比较渲染与输入）
- 搜索空间大（$SE(3)$ 是 6 维），通常需要先粗后精（coarse-to-fine）

### 2.3 基于直接回归（Direct Regression）

CNN 直接从图像输出 $\mathbf{R}, \mathbf{t}$。端到端可导。

- **PoseCNN（2017）：** 用霍夫投票（Hough Voting）找物体中心 + 四元数回归的经典方法
- **EfficientPose（2020）：** 轻量级，回归 6D 连续旋转表示 + 平移
- **GDR-Net（2022）：** 去噪 + 几何引导的直接回归

### 2.4 基于对应关系（Correspondence-based，主流）

分两步：先建立 2D 像素 ↔ 3D 物体坐标的稠密对应，再解 PnP。

- **密集对应（Dense Correspondence）：** 逐像素分类/回归到物体表面坐标
- **代表：** CDPN（2020）、EPOS（2020）
- **优势：** 间接但鲁棒，对遮挡不那么敏感

### 2.5 基于 Refinement（迭代精调）

先给一个粗略初始姿态，迭代细化为高精度姿态。

- **DeepIM（2018）：** 给定初始姿态 + 观测图像，用神经网络输出相对位姿的更新量
- **Render & Compare（渲染对比）：** 用当前姿态估计渲染物体，与输入图像比较差异，用梯度反传优化姿态
- **FoundationPose（2024）：** 面向通用物体的姿态估计，结合 NeuS-based 几何推理

## 三、评估指标

| 指标 | 含义 | 阈值 |
|------|------|:------:|
| **ADD（Average Distance of model points）** | 物体 3D 模型点用预测位姿与真值位姿变换后的平均 L2 距离 | < 模型直径 10% |
| **ADD-S（for symmetric objects）** | 对对称物体，取最近点距离（避免对称导致"正确姿态被误判为错误"） | < 模型直径 10% |
| **Proj. 2D（投影误差）** | 3D 模型点投影到 2D 的平均距离 | < 5px |
| **AUC（ADD/ADD-S 曲线下面积）** | 不同阈值下的召回率积分 | 越大越好 |
| **5° 5cm** | 旋转误差 < 5° 且平移误差 < 5cm 的占比（常见粗粒度成功率指标） | 一票通过 |

|------|:------:|------|:------:|
| **LINEMOD** | 15 个物体，~1k 帧 | 基准测试集，单一场景，竞争激烈基本已饱和 | 2011 |

## 五、在机器人学中的应用

### 5.1 机器人抓取（Grasping）

**核心链路：** 物体 6D 姿态 → 将抓取点从物体坐标系变换到机器人基座坐标系 → 规划轨迹 → 执行抓取。

- 这是 6D 姿态估计最直接、最经典的应用
- 精度要求取决于物体尺寸、夹爪余量和任务公差。粗抓取可能厘米级就够；插孔、装配、窄余量平行夹爪通常需要毫米级平移误差和较小角度误差，否则容易碰撞或夹偏

### 5.2 操作与组装（Manipulation & Assembly）

- 工具使用：识别扳手 / 螺丝刀的姿态 → 规划操作轨迹
- 零件装配：两端零件各自 6D 姿态 → 把 A 插进 B 的轨迹规划
- 双臂协作：跟踪目标物体的 6D 姿态作为手臂协同运动的约束

### 5.3 增强现实（AR）与人机交互

- AR 中虚拟物体稳定地"粘"在真实物体上
- 机器人示教（Teaching by Demonstration）：人操作物体，跟踪物体 6D 轨迹，映射为机器人动作

## 六、机器人中的底座到相机标定

姿态估计输出的是**物体在相机坐标系下的位姿**。要机器人执行，还需要把物体姿态从相机坐标系转换到机器人基座坐标系。

$$\mathbf{T}_{\text{robot}}^{\text{object}} = \mathbf{T}_{\text{robot}}^{\text{camera}} \cdot \mathbf{T}_{\text{camera}}^{\text{object}}$$

其中：
- $\mathbf{T}_{\text{camera}}^{\text{object}}$ ← 6D 姿态估计（估计的）
- $\mathbf{T}_{\text{robot}}^{\text{camera}}$ ← 手眼标定（Eye-in-Hand 或 Eye-to-Hand，标定的）
- $\mathbf{T}_{\text{robot}}^{\text{object}}$ ← 最终送给规划器的物体位姿

这个变换链中任何一个环节有误差，抓取就偏了。

## 七、关键概念速查

- **PnP（Perspective-n-Point）：** 从 n 对 2D-3D 对应点求解相机外参的算法，是传统姿态估计的核心
- **SE(3) / SO(3)：** SE(3) = 刚体变换群（旋转+平移），SO(3) = 旋转群（纯旋转）。两者都是光滑流形，不能用欧氏空间的简单 L2 距离度量
- **万向节死锁（Gimbal Lock）：** 欧拉角表示下，当其中一根轴旋转到与另一根轴对齐时，失掉一个旋转自由度。这就是为什么欧拉角不能用于回归
- **BOP（Benchmark for 6D Object Pose Estimation）：** 统一评测平台，将多个数据集和姿态估计算法放在同一框架下对比，每年举办 BOP Challenge
- **对称物体（Symmetric Object）：** 如球体、圆柱体、一些盒子——存在多个不同的旋转矩阵使物体看起来完全相同。需要用 ADD-S 评估，或用专门的对策角度公式计算"距离最近等价姿态"的误差
- **手眼标定（Hand-Eye Calibration）：** 求解相机相对机器人的位姿变换。Eye-in-Hand = 相机装在机械臂上随动，Eye-to-Hand = 相机固定在环境里不动
